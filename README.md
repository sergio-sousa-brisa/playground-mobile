# 🚀 Playground Flutter: Universo Cinematográfico com a API do IMDb

Este playground é uma proposta para você praticar e aprimorar suas habilidades em Flutter de forma leve e divertida, estudando aquilo que costumamos utilizar em nossos projetos. A ideia é construir um app focado no universo do cinema e da TV, consumindo dados da API do IMDb e explorando recursos variados do Flutter.



## Por onde começar

* Clone este repositório, crie um repositório privado no seu github da Brisanet e altere o remote do projeto usando `git remote set-url origin https://github.com/seu-usuario/seu-repositorio.git`, você pode conferir a alteração com `git remote -v`. Pronto! agora compartilhe o link com quem está te acompanhando nesta etapa.

## 🚀 O Desafio (ou melhor, a aventura)

Aqui na Brisanet nós também somos apaixonados por filmes e séries, então a proposta é o uso da API do IMDb(https://data.imdb.com/documentation/api-documentation/key-concepts/?ref_=side_nav) para explorar o desenvolvimento de uma aplicação com múltiplas telas e funcionalidades. A ideia é implementar os seguintes recursos:


  * login com persistência das informações do usuário;
  * Validar usuário e redirecionar caso haja um;
  * Lista de filmes (ex: Top 250, Lançamentos ou Populares);
  * Lista de atores/profissionais do cinema;
  * Lista de séries de TV.

## 🔧 Quer ir além? adicione:

  * Filtro para as listas (filmes, atores e séries);
  * Detalhes dos itens da lista;
  * Exibir a quantidade total de itens;
  * Utilize rotas nomeadas;
  * Tema escuro;
  * Salva as informações da api no banco local caso não haja conexão com internet;
  * Testes unitários.
